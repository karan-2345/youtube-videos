# How fast chess explodes: a vertical Short (1080 x 1920, 60 fps)

Twenty first moves, 400 games after one move each, 85 billion after four, Shannon's 10^120, and why even every
atom in the universe playing chess since the Big Bang would fall short. Built with three.js and ffmpeg; every move
count comes from our own legal move generator (`config/chess.py`), checked against the published perft tables.

Status, decisions and file map: `HANDOFF.md`. Run everything with `.venv\Scripts\python build.py <command>`.
