## Token saving (Ponytail)

The Ponytail plugin (github.com/DietrichGebert/ponytail) is enabled in `.claude/settings.json` to cut token use. It was set up on 2026-10-23 in youtube-videos, L-camera and Matter-lab. Change its strength with `/ponytail lite|full|ultra|off`. The other repos (DocuMind, stock-intel, password-generator, business-card, ecom-deploy-test) don't have it yet.
