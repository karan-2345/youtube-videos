# Beat plan v1: hidden in plain sight (1080 x 1920, 60 fps, everything important inside the 3:4 safe band y 240-1680)

Proposed look: **"Blueprint reveal"**, built in three.js like the chess Short. Each object is a clean, lit 3D model
(or a flat redraw for the logos) on a dark warm ground; the hidden thing is revealed by the same move every time:
the camera stops, everything except the secret dims, and the secret is traced in a cinnabar line (the chess
Short's accent colour). One move, repeated, so the viewer learns the "look for it" game in the first 5 seconds.
Type: Inter ExtraBold labels, Archivo captions, as approved for the chess Short.
